### Simplelith - a simple tool to transform a image into lithophane 3D model

#### Disclaimer: 
This project is in its early stages and improvements should be implemented in the near future.

#### Already implemented: 
- Tranform gray scale square image into lithophane using min and max thickness, size and resolution parameters (img_stl.py)
